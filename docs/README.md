## Матриця нефункціональних вимог (NFRs)

| ID | Категорія | Вимога | Метод перевірки |
| :-: | :--- | :--- | :--- |
| NFR-01 | Продуктивність | p95 READ-ендпоінтів ≤ 200 мс за 300 RPS | Locust/k6 |
| NFR-02 | Продуктивність | p95 створення бронювання ≤ 400 мс за 100 RPS запису | k6 |
| NFR-03 | Реальний час | p95 доставки події на екран бариста ≤ 1 с; ≥ 500 WebSocket-з'єднань | Тест з'єднань |
| NFR-04 | Консистентність | 0 подвійних бронювань із 1000 паралельних запитів на одне місце | Інтеграційний тест |
| NFR-05 | Автозвільнення | Звільнення броні через 20–30 хв з відхиленням ≤ 60 с | Тест Celery |
| NFR-06 | Автентифікація | JWT за OAuth 2.0, access ≤ 15 хв, refresh з ротацією, Argon2id, 4 ролі RBAC | Unit/integration |
| NFR-07 | Безпека | TLS ≥ 1.2, відповідність OWASP Top 10 | OWASP ZAP |
| NFR-08 | Безпека контейнерів | 0 CRITICAL та 0 виправних HIGH в образах | Trivy у CI |
| NFR-09 | Персональні дані | Мінімізація даних, токенізація платежів, GDPR | Аудит схеми БД |
| NFR-10 | Надійність | Доступність 99,5 %; Circuit Breaker для зовнішніх сервісів | Тест відмови |
| NFR-11 | Резервне копіювання | RPO ≤ 15 хв, RTO ≤ 60 хв | Тест відновлення |
| NFR-12 | Якість коду | Покриття ≥ 80 % для доменних модулів; Ruff і mypy без помилок | coverage.py, CI |
| NFR-13 | Спостережуваність | Метрики Prometheus, трасування OpenTelemetry | Grafana |
